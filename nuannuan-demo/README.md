# 暖暖心理 Demo

这是一个基于 React + Vite + TypeScript 的本地 Demo，用来演示“暖暖心理”的记忆闭环、风险分流、隐私封存和 AI 反哺上下文。当前实现只使用前端 seed data 与组件 state，不接入后端、账号系统或跨设备同步。

## 故事流

1. 普通低风险小记：用户聊到朋友关系，页面在“生成小记”中展示温和摘要，并可允许暖暖下次轻轻提起。
2. 中风险小记：用户表达持续压力和疲惫，页面只展示克制摘要，不展示强分析或原始表达。
3. 隐藏小记：用户点击“隐藏这条小记”后，小记从首页移除，并计入“隐私封存”。
4. 删除小记：用户点击“删除这条小记”后，小记从当前 Demo 状态移除，也不再进入 AI 反哺上下文。
5. 高风险安全引导：页面只展示“安全保护模式”和安全引导，不展示原文、细节或 `riskTags`。
6. AI 反哺上下文：页面底部的 Demo / 评审视图展示 `buildCompanionContext()` 输出，说明下次对话可使用的结构化 context。

## 运行命令

```bash
npm install
npm test
npm run build
npm run dev
```

启动 Demo 后，打开 Vite 输出的本地地址，通常是 `http://localhost:5173/`。

## 手动验收要点

- 确认页面标题为“暖暖安全小屋”，并展示“最近情绪”“常见烦恼”“情绪轨迹”“生成小记”“隐私封存”。
- 确认主页面没有展示“用户偏好”区块；偏好类信息只通过底部 AI 反哺上下文预览体现。
- 勾选或取消“允许暖暖下次温和提起”，确认 AI 反哺上下文预览中的 `mentionableMemorySummaries` 随之变化。
- 点击“隐藏这条小记”，确认该小记从首页消失，并从 AI 反哺上下文预览移除。
- 点击“删除这条小记”，确认该小记从当前页面消失，并不再参与上下文预览。
- 确认高风险记录只触发安全保护模式，不展示原文、具体事件细节、具体方法或 `riskTags` 文本。

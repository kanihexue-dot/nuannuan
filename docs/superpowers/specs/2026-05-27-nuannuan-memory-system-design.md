# 暖暖心理 MVP 记忆系统与我的页面设计文档

## 1. 背景与目标

暖暖心理 MVP 的核心定位是“轻心理、重陪伴”：用户可以在聊天或记录中表达情绪、梳理近况，并在后续使用中感受到 AI 逐渐理解自己，但产品不承担诊断、治疗或强分析职责。

何薛负责的范围包括“我的页面”和“记忆系统”。这两部分共同组成用户使用后的最终闭环：用户与暖暖完成固定三轮对话后，系统从这段完整对话中生成一颗候选心情小种子并完成风险分流；用户确认后，安全、允许展示的内容进入记忆花园；可用于陪伴体验的内容在下次聊天中轻量反哺 AI；高风险内容只触发安全引导，不沉淀原文或细节。

本设计文档的目标是明确 MVP Demo 阶段的产品边界、页面体验、数据结构、风险策略和 AI 反哺规则，确保后续实现聚焦在可演示、可解释、风险可控的闭环上。

## 2. 产品边界

暖暖心理不是诊断工具，也不是说教式心理咨询产品。MVP 中 AI 的表达应保持陪伴感、支持感和温和引导，避免给出医学诊断、人格判断、强因果分析或“你应该怎样”的指令式建议。

MVP Demo 阶段先采用前端本地存储模拟记忆系统，例如使用 `localStorage` 或等价的前端状态持久化方案。该阶段不接入后端数据库、不建设账号级长期记忆、不处理跨设备同步，也不实现复杂权限系统。

产品体验上采用“分级记忆闭环”：不同风险级别的内容进入不同处理路径。低风险和中风险内容可以在用户可控的前提下形成记忆；高风险内容不保存原文和细节，只保留必要风险标签并触发安全引导。

## 3. 整体闭环

整体闭环从用户完成固定三轮对话开始：

1. 对话缓冲：记录三轮用户和暖暖的对话，不在前两轮直接生成前台记忆。
2. 触发：第三轮结束后，系统判断这段对话已形成相对完整的情绪片段。
3. 提取：系统从三轮对话中提取情绪、主题、事件摘要、可反哺信息和潜在风险信号。
4. 候选种子：生成 `MemorySeedCandidate`，先作为用户可确认的候选内容。
5. 风险分流：根据低风险、中风险、高风险三档处理内容保存和页面展示策略。
6. 用户选择：用户选择 `带去记忆花园` 或 `先不保存`。
7. 保存：只保存符合边界的结构化信息，不保存不必要的敏感原文。
8. 我的页面展示：记忆花园展示用户确认留下的小种子。
9. AI 下次反哺：AI 在后续聊天中使用允许的记忆调整语气和回应方式，默认轻量，不主动翻旧账。

这个闭环的重点不是让系统“记住一切”，而是让用户在三轮对话后感觉这次心情被温和承接，并始终拥有是否带去记忆花园的控制权。

## 4. 我的页面 UI/UX

### 4.1 页面定位

我的页面定位为用户的“安全小屋”。它不是心理档案页，也不是数据报告页，而是一个让用户回看自己近况、管理记忆和确认安全感的空间。

页面语气应避免评判和分析感。例如使用“最近你常提到这些事”“这段时间情绪有些起伏”“有些内容已为你封存”这类表达，而不是“你的问题是”“你的心理状态显示”。

### 4.2 信息架构

MVP 中我的页面包含以下模块：

- 最近情绪：展示最近一次或最近几次记录中的主要情绪，例如焦虑、难过、疲惫、安心。
- 常见烦恼：展示用户最近反复提到的主题，例如朋友关系、学习压力、家庭沟通。
- 情绪轨迹：用轻量趋势展示情绪变化，不做诊断式解读。
- 生成小记：把一次聊天或记录整理成可读的小卡片，帮助用户回看。
- 隐私封存入口：让用户查看已隐藏或封存的记忆状态，并管理隐私。

用户偏好不在我的页面展示。偏好只隐藏存储，用于 AI 下次聊天时调整语气和互动方式，例如更适合短句陪伴、少提建议、先共情再回应。

### 4.3 普通状态

普通状态下，页面展示低风险和部分中风险的结构化内容。卡片应以“陪伴式回看”为主，避免把用户标签化。

生成小记可包含：

- 当时的主要情绪。
- 用户愿意保留的事件摘要。
- 轻量支持性总结。
- 是否允许 AI 下次温和提起。
- 删除和隐藏操作入口。

### 4.4 高风险状态

当系统识别到高风险内容时，我的页面不展示原文、事件细节或可复现的伤害信息。页面只展示安全引导状态，例如“有一段内容已进入安全保护模式”，并提供求助建议、紧急联系提示或安全资源入口。

高风险状态下，生成小记不应出现具体描述。AI 后续聊天也不应主动复述或暗示高风险细节，只能以更谨慎、支持性的方式询问用户当下是否安全。

### 4.5 查看、隐藏、删除与隐私封存

单条记忆在 MVP 中支持删除和隐藏，编辑后置。

- 查看：用户可以打开生成小记，查看系统保存的摘要和标签。
- 隐藏：隐藏后，该记忆不再出现在我的页面，也不再被 AI 主动提起；是否仍可用于非常轻量的语气适配需作为开放问题确认。
- 删除：删除后，该记忆从本地存储移除，不再展示，也不再参与 AI 反哺。
- 隐私封存：用于承载隐藏记忆、高风险风险标签和安全引导记录。封存状态强调“保护”和“可控”，不制造神秘感或恐惧感。

## 5. 记忆系统数据设计

MVP 只需要描述和保存前端可模拟的结构化数据，不需要引入后端实体或复杂索引。

### 5.0 三轮对话与候选种子

`ConversationTurn` 表示一轮用户和暖暖的对话。MVP 中固定收集 3 轮，前两轮只进入对话缓冲，不直接展示为记忆。

| 字段 | 用途 |
| --- | --- |
| `id` | 单轮对话唯一标识。 |
| `roundIndex` | 轮次，取值为 `1`、`2`、`3`。 |
| `userText` | 用户本轮表达。 |
| `aiResponse` | 暖暖本轮回应。 |
| `createdAt` | 本轮发生时间。 |

`ThreeRoundConversation` 表示固定三轮对话容器。

| 字段 | 用途 |
| --- | --- |
| `id` | 三轮对话唯一标识。 |
| `turns` | 3 条 `ConversationTurn`。 |
| `status` | 对话状态，例如 `collecting`、`ready_for_seed`、`seed_created`。 |
| `startedAt` | 开始时间。 |
| `completedAt` | 第三轮结束时间。 |

`MemorySeedCandidate` 表示三轮结束后生成、但尚未由用户确认的小种子。它不是正式记忆，不进入前台记忆花园。

| 字段 | 用途 |
| --- | --- |
| `id` | 候选种子唯一标识。 |
| `conversationId` | 来源三轮对话。 |
| `title` | 低压力标题，例如“有点小心翼翼的一天”。 |
| `summary` | 三轮对话沉淀出的简短摘要。 |
| `moodTags` | 心情标签。 |
| `topicTags` | 关联主题。 |
| `seedColor` | 小种子颜色，用于前台视觉。 |
| `aiResponse` | 暖暖对这次心情的总结回应。 |
| `riskLevel` | 候选内容风险等级。 |
| `candidateStatus` | `candidate`、`planted` 或 `not_saved`。 |

固定三轮规则是 MVP Demo 的显性规则：第三轮结束前不展示心情小种子；第三轮结束后才展示候选种子结果页。

### 5.1 `MemoryItem`

`MemoryItem` 表示一条可展示或可反哺的普通记忆。

| 字段 | 用途 |
| --- | --- |
| `id` | 单条记忆唯一标识。 |
| `createdAt` | 生成时间，用于排序和情绪轨迹。 |
| `sourceType` | 来源类型，例如 `chat` 或 `record`。 |
| `summary` | 生成小记摘要，避免保存长篇原文。 |
| `emotionTags` | 情绪标签，例如 `anxious`、`sad`、`calm`。 |
| `topicTags` | 主题标签，例如 `friendship`、`study_pressure`。 |
| `riskLevel` | 风险等级，取值为 `low`、`medium`、`high`。 |
| `allowMention` | 是否允许 AI 下次温和提起。 |
| `isHidden` | 是否从我的页面隐藏。 |
| `deletedAt` | 删除时间；MVP 可直接移除，也可软删除模拟。 |

### 5.2 `HiddenMemoryProfile`

`HiddenMemoryProfile` 表示不展示给用户的偏好和互动方式信息，用于 AI 下次聊天调整语气。

| 字段 | 用途 |
| --- | --- |
| `preferredTone` | 用户偏好的回应语气，例如更温柔、更简短。 |
| `interactionStyle` | 用户偏好的互动方式，例如少提建议、先陪伴。 |
| `avoidPatterns` | 需要避免的表达方式，例如说教、强分析。 |
| `updatedAt` | 最近更新时间。 |

该结构不在我的页面展示，只作为 AI 反哺的隐性上下文。

### 5.3 `RiskRecord`

`RiskRecord` 表示风险分流后的安全记录。高风险只保存必要标签，不保存原文和细节。

| 字段 | 用途 |
| --- | --- |
| `id` | 风险记录唯一标识。 |
| `createdAt` | 识别时间。 |
| `riskLevel` | 风险等级。 |
| `riskTags` | 风险标签，例如 `self_harm_signal`、`panic_signal`。 |
| `sourceMemoryId` | 关联的记忆标识；高风险可为空或只保留不可逆引用。 |
| `actionTaken` | 已触发的处理，例如安全引导、资源提示。 |

### 5.4 `SafetyGuideLog`

`SafetyGuideLog` 表示安全引导是否被触发、用户是否查看或关闭。

| 字段 | 用途 |
| --- | --- |
| `id` | 安全引导日志唯一标识。 |
| `riskRecordId` | 关联的风险记录。 |
| `guideType` | 引导类型，例如紧急支持、情绪稳定练习、求助资源。 |
| `shownAt` | 展示时间。 |
| `userAction` | 用户行为，例如查看、关闭、点击资源。 |

## 6. 风险分级

### 6.1 低风险

低风险包括一般情绪波动、学习压力、朋友关系困扰、轻度疲惫等。

低风险可以保存结构化摘要、情绪标签、主题标签和用户允许的反哺标记。我的页面可正常展示生成小记、最近情绪和常见烦恼。AI 下次聊天可根据 `allowMention` 温和提起，也可仅调整语气。

### 6.2 中风险

中风险包括持续强烈负面情绪、明显失眠或崩溃表达、反复无助感等，但未达到明确高风险标准。

中风险可以保存更克制的结构化摘要和风险标签，不保存过多细节。我的页面展示时应降低分析感，避免强化负面标签。AI 下次聊天默认不主动翻旧账，可在用户主动提到相关话题后温和承接。

### 6.3 高风险

高风险包括自伤、自杀、伤害他人或明确危机表达等。

高风险不保存原文、不保存具体方法、不保存事件细节。系统只保存风险等级、风险标签和安全引导记录，并立即触发安全引导。我的页面不展示具体内容，只展示安全保护状态。AI 后续不主动提及高风险细节，只在必要时关注用户当下安全。

## 7. AI 反哺规则

AI 反哺的默认原则是轻量、温和、可控。

AI 可以使用允许的记忆调整语气，例如更慢、更短、更陪伴，也可以在用户允许的情况下温和提起一条记忆，例如“上次你提到和朋友相处有点累，今天还和这件事有关吗？”

AI 不应主动翻旧账，不应把记忆当作判断用户的依据，也不应连续追问历史事件。隐藏记忆不在我的页面展示，也不应被 AI 主动提起。删除记忆不再参与任何展示或反哺。高风险后的后续对话应更谨慎，但不能复述或暗示高风险细节。

当 `allowMention` 为 `false` 时，AI 只能使用非常泛化的陪伴风格调整，不能提及具体事件、主题或时间点。当 `allowMention` 为 `true` 时，AI 仍需等待合适语境，避免在用户无关话题中突然提起历史内容。

## 8. MVP 范围

### 8.1 必须做

- 聊天或记录结束后生成 `MemoryItem`。
- 基于低、中、高三档完成风险分流。
- 我的页面展示最近情绪、常见烦恼、情绪轨迹、生成小记和隐私封存入口。
- 单条记忆支持删除和隐藏。
- 用户偏好隐藏存储，不在我的页面展示。
- AI 下次聊天支持轻量反哺，且只温和提起允许的记忆。
- 高风险内容不保存原文或细节，只保存风险标签并触发安全引导。

### 8.2 可简化

- 情绪轨迹可先用简单列表或基础趋势模拟，不需要复杂图表。
- 风险识别可先用前端规则或 mock 结果模拟，不需要完整模型能力。
- 隐私封存入口可先展示封存数量和说明，不需要复杂管理页。
- `deletedAt` 可在 MVP 中用直接删除替代。

### 8.3 后置

- 单条记忆编辑。
- 跨设备同步和账号级长期记忆。
- 更细粒度的隐私权限。
- 复杂风险审核流程。
- 记忆恢复、导出和批量管理。
- 多维度心理量表或诊断类报告。

## 9. 完整案例

用户和暖暖完成固定三轮对话：

1. 用户：“最近和朋友关系有点僵，我不知道是不是自己太敏感了。她回消息很慢，我就会一直想是不是我哪里做错了。”
2. 暖暖先共情并追问：“你很在意这段关系，所以她慢一点回应时，你会先怀疑自己。最近有没有哪一次让这种感觉特别明显？”
3. 用户补充后，暖暖在第三轮总结：“这次更像是一颗有点小心翼翼的小种子，它带着不安，也带着你想靠近朋友的愿望。”

系统在第三轮结束后生成 `MemorySeedCandidate`：

- 情绪：焦虑、委屈。
- 主题：朋友关系。
- 风险等级：低风险。
- 候选种子摘要：最近你有点在意和朋友之间的距离感，尤其是对方回消息变慢时，会担心是不是自己做错了什么。
- 反哺设置：默认不主动提起；用户可选择允许 AI 下次温和提起。

用户点击 `带去记忆花园` 后，候选种子转为正式 `MemorySeed`，出现在记忆花园中。用户点击 `先不保存` 后，它不进入前台记忆花园。

如果用户允许 AI 下次温和提起，下一次聊天中，当用户再次说“今天又因为她回消息慢有点烦”时，AI 可以回应：“这好像和你之前提到的朋友关系有一点相似，我先陪你把今天最难受的部分说清楚，好吗？”如果用户聊的是完全无关的话题，AI 不主动提起这段记忆。

如果同类内容在后续升级为高风险表达，系统不再保存具体原文或细节，只记录风险标签，触发安全引导，并在我的页面以隐私封存状态呈现。

## 10. 开放问题

1. 隐藏后的记忆是否允许用户恢复，还是 MVP 中只支持隐藏后不可见、删除后移除。
2. `allowMention` 的入口是否放入 MVP，例如在生成小记卡片上提供“允许暖暖下次温和提起”开关。
3. 隐藏记忆是否仍可用于极轻量语气适配，还是完全从 AI 反哺上下文中排除。

## 11. Spec Self-Review

本设计已检查并修正以下问题：

- 未保留占位标记。
- MVP 边界聚焦在前端本地存储模拟，没有扩展到后端、账号系统或跨设备同步。
- 高风险处理与 AI 反哺规则保持一致：不保存原文和细节，不展示具体内容，不主动复述。
- 三轮对话规则与候选种子规则保持一致：第三轮结束前不生成前台小种子，第三轮后先生成 `MemorySeedCandidate`，用户确认后才进入 `MemoryGarden`。
- 用户偏好不展示，只隐藏存储，并仅用于 AI 语气和互动方式调整。
- 开放问题只保留当前产品决策仍需确认的事项。

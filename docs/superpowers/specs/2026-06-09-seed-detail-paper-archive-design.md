# 暖暖心理 · 种子详情终页纸本珍藏页设计

日期：2026-06-09  
状态：已完成对话式 brainstorming，对齐为高保真 v2 方向  
适用范围：记忆小花园中单颗种子的最终详情页

## 1. 目标

把当前“列表上浮白色详情弹层”的种子详情，改成一张完整的、单屏固定的纸本珍藏页。

本页不做向下滚动，不做二级跳转，不再像说明弹窗。用户进入后，直接看到一颗被暖暖收藏起来的情绪种子。

## 2. 定位

最终页采用“记忆祭坛 + 成长标本”的融合方向，但视觉基调明确收束为：

- 纸本珍藏页
- 安静
- 克制
- 温柔
- 被收藏感

不是数字轻奢 UI，不是功能型详情页，也不是长内容说明页。

## 3. 固定内容层

本页固定保留以下五层内容：

1. 主视觉
2. 三个标签
3. 暖暖回响
4. 你留下的话
5. 成长状态

不额外引入时间线、长对话全文、复杂交互、二次展开区。

## 4. 单屏结构

### 4.1 整页母体

- 整张页面本身就是一页收藏页
- 不是背景加卡片容器
- 底色有浅奶油纸感、轻纤维感、留白感
- 花园元素仅留在边角，像装帧痕迹

### 4.2 上半屏，主视觉祭坛

- 占整屏约 45%
- 种子直接被安放在页面中央，不放入明显大白卡
- 下方使用轻托垫 / 标本托底，而不是 UI 卡片底座
- 标题采用题签感：
  - 主标题：种子名字
  - 副句：一行极轻的背景说明
- 日期与状态以小注记形式贴在主视觉下沿

### 4.3 中段，标本注记层

中段采用“被摆放”的纸本注记关系，而不是模块化卡片堆叠：

- 三个标签：像贴在纸页上的小签条
- 暖暖回响：中段主注释，视觉权重最高
- 你留下的话：像夹在页里的原话纸签

三者关系：

- 标签最轻
- 暖暖回响最重
- 原话最真

### 4.4 底部，成长结语层

- 不使用 badge、时间轴或进度条
- 改成页脚式馆藏结语
- 表达方式为：
  - 一句成长状态短句
  - 一句更轻的结语

整页最后落点应是：

“这颗种子没有停在那天，它已经慢慢长了一点。”

## 5. 视觉规则

### 5.1 页面气质

- 浅奶油纸感
- 柔白留白
- 轻装帧边角
- 中心不被花朵、叶片或装饰物抢走

### 5.2 主视觉

- 种子是整页第一视觉
- 不再作为缩略图或卡片配图存在
- 光晕可以保留，但必须克制
- 页面不靠大面积情绪色铺底

### 5.3 标签

- 像珍藏注记，不像按钮
- 一个标签略贴主情绪色
- 另外两个更浅、更静
- 允许轻微错位，但不能凌乱

### 5.4 暖暖回响

- 是被接住的一句话
- 不是分析结论
- 是中段的主注释，不是普通正文块

### 5.5 你留下的话

- 更接近原话纸签
- 更克制、更素
- 不能与暖暖回响抢主次

### 5.6 成长状态

- 更像馆藏备注，不像系统状态控件
- 用于整页收尾，而不是补充更多信息

## 6. 禁止事项

- 禁止做成白色详情弹层
- 禁止做成多卡片拼接的 UI 面板
- 禁止做成长滚动详情页
- 禁止出现明显“按钮式标签”
- 禁止把成长状态做成时间线或游戏进度
- 禁止让装饰元素进入中心抢主视觉

## 7. 本轮高保真输出目标

基于本 spec，重做一张单屏高保真 v2 终页，满足：

- 一屏完整看完
- 更像纸本珍藏页，而不是 App 卡片组合
- 比当前 v1 方案更弱化 UI 卡片感
- 主视觉、标签、暖暖回响、原话、成长结语层级更明确

## 8. 用户确认状态

本轮对话中，用户已逐段确认：

- 选择最终页面为单屏固定终页
- 采用“记忆祭坛 + 成长标本”融合方向
- 最终精修版收束到“高级标本版 v2”
- 视觉基调选择为“纸本珍藏页”
- 已逐段确认：
  - 页面母体与上半屏主视觉
  - 中段标本注记层
  - 底部成长结语层
  - 单屏总构图

下一步可基于此 spec 直接产出高保真 v2。
